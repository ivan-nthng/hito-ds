# Storybook font assets

Unmodified WOFF2 files served locally by the Storybook build, downloaded from Google Fonts on 2026-10-30. `provenance.json` records the exact source URL and SHA256 of each file. Original OFL 1.1 licenses are included per family. No runtime or build-time Google font request is needed.

Accepted normal styles: Instrument Sans variable 400–700; Poppins 400/500/600/700; Fira Mono 400/500/700. Latin and Latin Extended subsets retain the provider Unicode ranges. They do not add a new design direction or replace semantic tokens.
