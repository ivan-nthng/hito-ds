# Hito DS

This is a standalone open-source design system. Keep source product repositories unchanged.

Use existing components, semantic tokens and CSS Modules. Keep Figma, code and Storybook mappings explicit; never claim automatic synchronization that is not implemented. Preserve the inherited public component APIs unless a change is documented.

Before shipping, run type checking, relevant unit/interaction tests, token validation and the Storybook build. Public examples use synthetic data. Do not add backend credentials, private source links, product records or environment files.
