# Media landing recipe

The Hito home page composes the existing library: `Text`, `Card`, `Breadcrumbs`, `Button`, `Link`, `Tag` and `Separator`. Its dark neutral outer page and explicitly light raised Card demonstrate independent theme and color-scheme scopes. Card defaults and existing component APIs are unchanged.

The additive `Dot`, `Live`, `MediaBackdrop`, `RoundPlayButton`, `MediaActionLink` and `MediaFooter` helpers live in the React package. `RoundPlayButton` wraps the native XL primary/accent Button; `MediaActionLink` remains a real anchor. `MediaFooter` derives a normal-flow full-bleed divider from the fixed compact Card's inset. Consumers own destinations, accessible action labels and state.

`Live` animates only its semantic success dot from opacity 1 to .45 and back every 1.92 seconds, continuously. `prefers-reduced-motion: reduce` leaves a static dot and label. The six-object background is a static, fixed viewport layer, independent of scrolling or expanded content. Its overscanned field follows viewport width and height (124%, −12% anchor), using the implemented source blur clamp44px–100px at7vw and52px below600px. Six isolated SCREEN forms remain under the original256px grain tile at .18 opacity; neutral brightness/contrast restore the actual source's visible fine texture. The former document-height overhang parameter remains a neutral reserved compatibility value and is no longer consumed. A local feathered semantic scrim follows only the footer copy/link group to preserve contrast as foreground scrolls over the fixed colors; it does not dim the whole field or change the footer layout. Its geometry and three exact source colors are bounded recipe parameters in `tokens/media-recipe.mjs`, exported as `@hito-ds/react/tokens/media-recipe`; they do not introduce general palette families or alter canonical canvas tokens. Regenerate its adapter with `node packages/design-system/tokens/build-media-recipe.mjs`, then run token validation.

The site owns the original coastal photograph export and synthetic session content. The served JPEG removes metadata without re-encoding the image; its adjacent provenance JSON records hashes. This asset belongs to the site, not the component package. Play/Pause changes demonstrative local state without streaming audio, Save is reversible for the current visit, and View Tracklist opens a local accessible disclosure. Nothing is submitted or remotely stored.

At the approved desktop/mobile widths, the Card is 448/358px wide with a centered 3:2 photo. Local radius and inset parameters retain the approved composition while leaving shared Card behavior intact. The narrow layout wraps tags, actions and navigation naturally.

Build with `npm run build` and validate the composed artifact with `npm run verify:site`. To replay against an already serving deployment, use `npm run verify:site -- https://www.hitocajon.com` (only after that deployment contains this recipe). The verifier checks root and nested Storybook navigation, assets, real missing-file responses, keyboard access, local control states, actual fonts, repeated Live beyond the native finite-export duration and reduced motion. It also checks package isolation and preserved public exports. This verification does not assert automatic Figma synchronization.
